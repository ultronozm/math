Prime number theorem and zero-free regions

Abstract

Notes from a lecture on 13 Dec 2018 at ETH Zürich, where I substituted for Ian Petrow’s course on analytic number theory and presented a proof of the basic zero-free regions for the zeta function.

  • Overview
  • Proof of the qualitative zero-free region
  • Quantitative zero-free region
  • How to make the proof seem more mysterious

§1. Overview

Last time, Ian explained how the quantitative zero-free region implies the quantitative prime numbers theorem: if \[\zeta(\beta + i t) = 0 \implies 1 - \beta \gg \frac{1}{\log(2 + |t|)},\] then \[\sum_{n \leq x} \Lambda(n) = x + \operatorname{O}(\exp(- c \sqrt{\log x})) = x ( 1 + O(\log^{-A} x)).\] Today we aim to prove the quantitative zero-free region, thereby establishing the quantitative prime number theorem.

As warm-up, we prove a qualitative zero-free region: \[\label{eqn:qual-zfr}\tag{3} \zeta(\beta + i t) \implies 1 - \beta > 0, \text{ i.e., } \beta = 1.\] This implies a qualitative prime number theorem \[\sum_{n \leq x} \Lambda(x) = x + o(x)\] by the same argument as last time.

§2. Proof of the qualitative zero-free region

At the point \(s = 1\), the zeta function \(\zeta\) has a simple pole, so its negative logarithmic derivative \(- \zeta ' / \zeta\) has a simple pole with residue \(1\). Thus for \(\sigma > 1\), \[\label{eq:zeta-1}\tag{5} \sum_{n} \frac{\Lambda(n)}{n^{\sigma} } = - \frac{\zeta '}{ \zeta } (\sigma) = \frac{1}{\sigma - 1} + \operatorname{O}(1).\] Note that the right hand side tends to \(\infty\) as \(\sigma \rightarrow 1^+\).

At \(s = 1 + it\) with \(t \neq 0\), \(\zeta\) is holomorphic. Let \(\ell \geq 0\) denote its order of vanishing. Then \(- \zeta ' / \zeta\) has a simple pole with residue \(- \ell\), and so \[\label{eqn:zeta-1-it}\tag{6} \sum_{n} n^{-i t} \frac{\Lambda(n)}{n^{\sigma} } = - \frac{\zeta '}{ \zeta } (\sigma + i t) = \frac{-\ell }{\sigma - 1} + \operatorname{O}_t(1).\] Comparing \((5)\) with \((6)\) and using that \(\Lambda(n) \geq 0\) and \(|n^{i t}| \leq 1\), we see that \(\ell \leq 1\). We wish to show that \(\ell = 0\), so we suppose for the sake of contradiction that \(\ell = 1\).

The informal idea is now that \((5)\) and \((6)\) say that when \(\Lambda(n) \neq 0\), we have \(n^{-i t} \approx -1\); but then \(n^{- 2 i t} \approx 1\), which contradicts the following consequence of \((6)\) (applied to \(2 t\) instead of \(t\)): \[\label{eq:upper-zeta-1-2it}\tag{7} \sum_{n} n^{-2 i t} \frac{\Lambda(n)}{n^{\sigma} } \leq \operatorname{O}_t(1).\]

To implement this idea rigorously, we need to make precise the idea that \[n^{-i t} \approx -1 \implies n^{-2 i t} \approx 1.\] Let’s start simple, with what is essentially the continuity of \(z \mapsto z^2\) at \(z = -1\):

For each \(\varepsilon> 0\) there exists \(\delta > 0\) so that \(\Re(n^{-it}) < -1 + \delta \implies \Re(n^{-2 i t}) > 1 - \varepsilon\).

Taking real parts in \((5)\) and \((6)\) gives \[\sum_{n : \Re(n^{-2 i t}) \leq 1 - \varepsilon} \frac{\Lambda(n)}{n^\sigma } \leq \sum_{n : \Re(n^{-i t}) + 1 \geq \delta } \frac{\Lambda(n)}{n^\sigma } \leq \frac{1}{\delta } \sum_n (\Re( n^{-i t}) + 1) \frac{\Lambda(n)}{n^\sigma } = \operatorname{O}_t(\frac{1}{\delta }),\] thus \[\begin{align} \label{eq:}\tag{24} \sum_{n} (1 - \Re(n^{-2 i t})) \frac{\Lambda(n)}{n^\sigma } &= \sum_{n : 1 - \Re(n^{-2 it}) \geq \varepsilon} \dotsb + \sum_{n : 1 - \Re(n^{-2 it}) < \varepsilon} \dotsb \\ &\leq C_t (\frac{1}{\delta } + \frac{\varepsilon}{\sigma - 1}), \end{align}\] say. Choose \(\varepsilon= 1 / 10 C_t\), and take \(\sigma\) close enough to \(1\) that \(\sigma - 1 \leq \delta/10 C_t\). Then the above estimate reads \[\label{eq:}\tag{24} \sum_{n} (1 - \Re(n^{-2 i t})) \frac{\Lambda(n)}{n^\sigma } \leq \frac{2/10}{\sigma - 1}.\] Using \((5)\), it follows that \[\sum_{n} \Re(n^{-2 i t}) \frac{\Lambda(n)}{n^\sigma } \geq \frac{8/10}{\sigma - 1} + \operatorname{O}(1).\] But this contradicts \((7)\) upon taking \(\sigma \rightarrow 1^+\).

This completes the proof of the qualitative zero-free region, hence of the qualitative prime number theorem.

§3. Quantitative zero-free region

We need to clean up the above argument and make explicit how everything depends upon \(t\). First, we recall the following estimate from last time, a consequence of factorization theory for holomorphic functions: for \(s = \sigma + i t\) with \(|\sigma| \leq 10\), \[\zeta(s) = \frac{\prod_{\rho : |s - \rho| < 1} (s - \rho)}{s - 1} \exp(\operatorname{O}(\mathcal{L})), \quad \mathcal{L} := \log(2 + |t|),\] or equivalently, \[- \frac{\zeta ' }{\zeta }(s) = \frac{1}{s - 1} -\sum_{\rho : |s - \rho| < 1} \frac{1}{s - \rho} + \operatorname{O}(\mathcal{L}).\] Note that for \(|s-1| \gg 1/\mathcal{L}\) (e.g., for \(|t| \gg 1/\mathcal{L}\)), we can absorb the first term \(\frac{1}{s - 1}\) into the error term.

Suppose henceforth that \(\sigma > 1\). Since each \(\rho\) has real part at most \(1\), it follows that each fraction \(\frac{1}{s - \rho }\) has positive real part when \(s = \sigma + i t\). Thus for \(|t| \gg 1/\mathcal{L}\), \[\label{eq:log-der-up}\tag{17} - \Re \frac{\zeta ' }{\zeta }(\sigma + i t) \leq \operatorname{O}(\mathcal{L}).\]

Suppose now that \(\zeta(\beta + i t) = 0\). We aim to show that \(1 - \beta \gg \frac{1}{ \mathcal{L} }\), with the abbreviation \(\mathcal{L}\) as above. Since \(\zeta\) has a pole at \(s = 1\), we know that it has no zeros in that region. So we may suppose that \(|t| \gg 1\). We improve upon \((17)\) by taking into account the contribution from \(\rho = \beta + i t\): \[\label{eq:log-der-up}\tag{17} \sum_n \Re(n^{-it}) \frac{\Lambda(n)}{n^\sigma } = - \Re \frac{\zeta ' }{\zeta }(\sigma + i t) \leq -\frac{1}{\sigma - \beta } + \operatorname{O}(\mathcal{L}).\] As before, we use \((5)\) to write this as \[\label{eq:log-der-up-2}\tag{18} \sum_n (1 + \Re(n^{-it})) \frac{\Lambda(n)}{n^\sigma } \leq \frac{1}{\sigma - 1} - \frac{1}{\sigma - \beta } + \operatorname{O}(\mathcal{L}).\] We note also by \((5)\) and \((17)\) (applied to \(2 t\)) that \[\label{eq:quant-est-n-2-it}\tag{19} \sum_n (1 - \Re(n^{-2 it})) \frac{\Lambda(n)}{n^\sigma } \geq \frac{1}{\sigma - 1} + \operatorname{O}(\mathcal{L}).\]

We aim now to implement more quantitatively the idea that \(n^{-i t} \approx -1 \implies n^{- 2 i t} \approx 1\). To that end, let’s write \(n^{-i t} = e^{i \theta}\), so that \(\Re(n^{-it}) + 1 = \cos(\theta) + 1\) and \(1 - \Re(n^{-2 i t}) = 1 - \cos(2 \theta)\). These quantitaties are related by the formula \(\cos(2 \theta) = 2 \cos^2(\theta) - 1\), from which we deduce that \[\label{eq:}\tag{24} 1 - \cos(2 \theta) = 2 (1 - \cos^2(\theta)) = 2 (1 - \cos(\theta)) (1 + \cos(\theta)) \leq 4 (1 + \cos(\theta)),\] or equivalently, \[\label{eq:}\tag{24} 1 - \Re(n^{-2 it}) \leq 4 (1 + \Re(n^{- it})).\] Inserting this into \((18)\) and \((19)\) gives \[\label{eq:}\tag{24} \frac{1}{\sigma - 1} \leq 4 \left( \frac{1}{\sigma - 1} - \frac{1}{\sigma - \beta } \right) + \operatorname{O}(\mathcal{L}),\] which may be rearranged as \[\label{eq:}\tag{24} \frac{4}{\sigma - \beta } - \frac{3}{\sigma - 1} \leq \operatorname{O}(\mathcal{L}).\] We choose \(\sigma\) so that \(\sigma - 1 = (1 - \beta)/\varepsilon\) for some small enough \(\varepsilon> 0\); note that if \(\beta\) is close enough to \(1\), then \(\sigma < 10\). Then \(\sigma - \beta = (1 + 1/\varepsilon) (1 - \beta)\), so the above estimate reads \[\label{eq:}\tag{24} \frac{1}{1 - \beta } \left( \frac{4}{1 + 1/\varepsilon} - 3 \varepsilon \right) \leq \operatorname{O}(\mathcal{L}).\] Taking \(\varepsilon= 1/4\) (say) leads to the required estimate \(1 - \beta \gg 1/ \mathcal{L}\).

§4. How to make the proof seem more mysterious

We can rewrite the key trigonometric inequality as \(1 - \cos(2 \theta) \leq 4 (1 + \cos(\theta))\) as \(3 + 4 \cos(\theta) + \cos(2 \theta) \geq 0\), i.e., \[3 + 4 \Re(n^{-i t}) + \Re(n^{-2 it}) \geq 0,\] hence \[- \frac{\zeta '}{ \zeta }(\sigma) + 4 \frac{\zeta '}{ \zeta }(\sigma+it) + \frac{\zeta '}{ \zeta }(\sigma+2 it)\] has nonnegative real part for any \(\sigma > 1\), and then integrating gives \[|\zeta(\sigma)|^3 |\zeta(\sigma + it)|^4 |\zeta(\sigma + 2 it)| \geq 1.\] So we can interpret the above proof in terms of orders of poles, etc.
